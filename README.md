# VkVideoTests
Тесты для VK Видео

Сделал топорное решение "в лоб". Задержки sleep(10000) для ожидания полной загрузки.

Тесты работают в связке с:
Appium v.3.2.2 с UiAutomator2 v.7.0.0
Android Studio 2025.3.2 Panda 2, Virtual Device API 30 "R";Android 11.0;Google Play Intel x86 Atom System Image

Запуск тестов: mvn clean install
